# 🧮 Simple Calculator

A clean, fully functional web-based calculator built from scratch. 

## 🚀 Live Demo
You can try the live calculator here: [https://bshree4-alt.github.io/Simple-Calculator/](https://bshree4-alt.github.io/Simple-Calculator/)

- **Basic Math Operations:** Addition, subtraction, multiplication, and division.
- **Clean Interface:** A user-friendly design that is easy to read.
- **Responsive:** Works on desktop and mobile devices.

- CSS3
- Vanilla JavaScript (DOM Manipulation and Math logic)
